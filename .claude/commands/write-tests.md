# Command: Write Tests

When asked to write tests, use this process.

## Process
1. understand the behavior under test
2. inspect current test patterns
3. identify critical scenarios
4. write focused tests
5. avoid implementation-detail assertions
6. summarize coverage

## Default scenarios
Include as relevant:
- render
- success flow
- validation or guard rails
- failure flow
- edge cases

## Output format
- scope under test
- scenarios covered
- any gaps or assumptions
