# Command: Build Feature

When asked to build a feature, follow this process.

## Process
1. restate the requested feature briefly
2. identify relevant files and patterns
3. propose a short implementation plan
4. implement the smallest complete solution
5. update tests if behavior changes
6. summarize what changed

## Requirements
- prefer existing patterns
- keep changes scoped
- do not over-abstract
- handle loading/error states where relevant
- note any assumptions clearly

## Response format
- task understanding
- plan
- implementation summary
- test notes
- follow-up notes
