# Command: Explain Code

When asked to explain code, use this structure.

## Process
1. explain the overall purpose
2. explain important inputs
3. walk through the flow step by step
4. explain outputs and side effects
5. mention notable dependencies or assumptions

## Tone
- simple
- clear
- practical
- beginner-friendly when needed

## Response format
- what this file/function does
- how it works
- key dependencies
- things to watch out for
