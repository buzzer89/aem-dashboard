# Skill: Form Handling

Use this for form creation or updates.

## Form principles
- keep validation predictable
- surface clear user feedback
- prevent invalid submission when possible
- keep submit flow understandable

## Checklist
- default values make sense
- required fields are enforced
- validation messages are clear
- pending submit state is handled
- success and failure outcomes are visible

## Avoid
- vague error messages
- hidden validation rules
- duplicate validation logic scattered across files
- disabled interactions without explanation
